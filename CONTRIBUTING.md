# Contributing

Thanks for helping maintain this repository.

## Project Scope

This repository is focused on airspace data for gliding use only.

## Data Inclusion Rules

When editing airspace data, apply these rules:

- Airspaces below 500 m are discarded.
- Airspaces over the sea are discarded.

## Source of Truth

- Only `france-exp.txt` should be modified manually.
- All other generated files in this repository are produced automatically from `france-exp.txt`.
- 
See [README.md](README.md)

## Standard Git Procedure

Follow this process for every contribution:

1. Work in a branch.
2. Validate `france-exp.txt` from your branch using the workflow:
   https://github.com/planeur-net/airspace/actions/workflows/validate-branch.yml
3. Submit a pull request.

## Branch Validation Notes

- The branch validation workflow runs automatically on push to `feature/*` and `autogenerated/*` when `france-exp.txt` changes.
- You can also run it manually from the Actions tab and choose the input file.

## Pull Request Expectations

Before opening a pull request:

- Ensure the validation workflow is green.
- Keep changes focused and easy to review.
- In the PR description, summarize what changed and why.
- Add reference (SUP-AIP, ...) when possible.
